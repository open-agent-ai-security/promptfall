# Promptfall — First Playable Skeleton

This folder is a complete static website. Upload its contents to GitHub Pages or any ordinary static web server; no backend or runtime configuration is required.

## Controls

- Move: `A` / `D` or Left / Right Arrow
- Jump: `W`, Up Arrow, or Space
- Sound toggle: `M`
- Mobile: on-screen movement and jump controls

## Current mission

Find each LLM vulnerability, land on it from above to contain it, then cross the force field.
