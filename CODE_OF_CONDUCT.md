# Code of Conduct

The Promptfall project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. The full text is the canonical source; this file states
only the project-specific reporting and enforcement details the Covenant requires.

This applies to every project space — issues, pull requests, code reviews,
discussions, and any other contact made in a Promptfall context, on or off GitHub.

## Reporting

If you experience or witness conduct that you believe violates the Contributor
Covenant, report it privately to the project maintainers at **developer@exabeam.com**.
Include enough context to understand what happened, when, where, and who was
involved. Reports are handled by the maintainers and treated as confidential.

## Enforcement

Maintainers are responsible for clarifying and enforcing the standard. They will
follow the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
— correction, warning, temporary ban, permanent ban — proportionate to the
violation, and will communicate the outcome to the reporter where appropriate.
